# AI-Powered Human Resource Management System (AI-HRMS)

## Project Overview
AI-HRMS is a full-stack Human Resource Management System designed to simplify and automate HR operations using Java, Spring Boot, React, and AI-based capabilities.

## Technologies Used

**Backend**
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- REST APIs
- MySQL / H2 Database
- JWT Authentication

**Frontend**
- React.js
- Material UI (MUI)
- JavaScript
- HTML5 / CSS3
- Recharts

## Key Features

- User Authentication and Authorization
- Employee Management
- Department Management
- Attendance Management
- Leave Management
- Payroll Management
- Performance Management
- Recruitment and Candidate Management
- Dashboard with HR Statistics
- AI-based Resume Screening (planned / in development)
- AI Interview Question Generation (planned / in development)

## Project Architecture

- Frontend: React.js
- Backend: Spring Boot REST APIs
- Database: MySQL / H2
- Authentication: JWT and Spring Security

- `AI-HRMS-frontend.zip` – Frontend source code
